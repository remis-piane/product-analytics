# Разработка A/B-тестирования и анализ результатов

## О проекте

Приложение с «бесконечной» лентой коротких видео. Монетизация — подписка и реклама. Команда рекомендательных систем создала новый алгоритм, который должен показывать более интересный контент. Нужно рассчитать параметры A/B-теста, проверить корректность его проведения и проанализировать результаты.

## Данные
Исторические данные о сессиях пользователей приложения с функцией «бесконечной» ленты, а также данные за период проведения A/B-теста (октябрь-ноябрь 2025).

## Задача
Рассчитать параметры A/B-теста (размер выборки, длительность) для проверки нового алгоритма рекомендаций. Оценить корректность проведения эксперимента (равномерность сплита) и проанализировать результаты по ключевой метрике — доле успешных первых сессий.

## Используемые библиотеки
*pandas, numpy, matplotlib, seaborn, statsmodels, scipy*

## Ключевые выводы
- Фактический размер выборки оказался ниже планового, мощность теста снижена.
- Ключевая метрика не показала статистически значимых различий (p-value ≈ 0.84). 
- **Рекомендация:** не внедрять алгоритм в текущем виде. Команде разработки стоит доработать модель и перезапустить тест.
- **Рекомендация:** не внедрять алгоритм в текущем виде. Если команда считает его перспективным — доработать модель и перезапустить тест с более сильной ожидаемой разницей или другим набором метрик
