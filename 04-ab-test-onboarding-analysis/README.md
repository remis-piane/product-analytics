# Исследование результатов A/B-теста и поиск инсайтов

## О проекте

Международное мобильное приложение для онлайн-торговли финансовыми активами (акции, валюта, криптовалюта, ETF). Рынок Латинской Америки: Мексика, Бразилия, Колумбия, Аргентина. Команда продукта обновила онбординг, добавив детальную информацию о рисках активов. Опасение: углублённый онбординг может отпугнуть клиентов от первого депозита. Проверяю это с помощью A/B-теста.

## Данные
Данные международного финтех-приложения за апрель-июнь 2025 года: исторические данные по новым пользователям и данные A/B-теста по внедрению нового онбординга.

## Задача
Оценить, как обновленный онбординг с информацией о рисках влияет на инвестиционную активность. Сравнить контрольную и тестовую группы по ключевым метрикам (конверсия, сумма депозитов), а также провести исследование поведения платящих пользователей с помощью бутстрапа.

## Используемые библиотеки
*pandas, numpy, matplotlib, seaborn, statsmodels, scipy*

## Ключевые выводы
- Ключевая метрика не изменилась, барьерная метрика осталась на прежнем уровне.
- Конверсия во второй депозит и средний чек платящих пользователей значимо выросли.
- **Инсайт:** онбординг отпугнул мелких вкладчиков (суммы упали почти вдвое), но крупные инвесторы стали вкладывать больше.
- **Рекомендация:** не внедрять в текущем виде, смягчить подачу информации о рисках для консервативной аудитории.
