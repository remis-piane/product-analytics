# Обзор бизнес-показателей маркетплейса

### Данные
В наличии были данные о работе маркетплейса за 2024 год:
- Информация о пользователях (`Users`).
- Логи событий в продукте (`Events`).
- Информация о заказах (`Orders`).
- Расходы на маркетинговые кампании (`Campaign_costs`).

### Задача
Провести комплексный аудит продукта: 
- Рассчитать ключевые метрики (DAU, WAU, MAU, Retention, конверсии).
- Оценить юнит-экономику (ARPU, ARPPU, AOV, CAC, ROI).
- Найти точки роста и аномалии в разрезе каналов, регионов, устройств и категорий товаров.
- Спроектировать и проанализировать A/B-тест бонуса на первую покупку для пользователей, привлеченных через TikTok.

### Используемые библиотеки
*pandas, numpy, matplotlib, seaborn, scipy, statsmodels, plotly*

### Ключевые выводы
- **Кризис каналов:** Перевод бюджета в TikTok (82,5% расходов) обвалил продажи. Убыточный канал (ROI -89%) принес дешевый, но нецелевой трафик, из-за чего просели дорогие категории. Лидеры по окупаемости — Affiliate (ROI 255%) и SEO (ROI 207%).
- **Инсайты по аудитории:** Пик покупок приходится на вечер пятницы и субботу. Самые провальные дни — воскресенье и понедельник. Ядро выручки — мебель, бытовая техника и украшения.
- **A/B-тест (Бонус на 1-ю покупку):** Механика показала взрывной эффект. Конверсия выросла с 1,06% до 7,51% (p < 0.001), ARPU — с 251 до 2 625 руб. Общая выручка от сегмента выросла на 916%.
- **Рекомендации:** Масштабировать бонусную механику, перераспределить бюджет в Affiliate и SEO, запустить кампании по возврату (retention) для сегмента разовых покупателей из TikTok.
