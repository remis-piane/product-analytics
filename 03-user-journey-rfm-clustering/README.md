# Поиск инсайтов и точек роста

## О проекте

Сервис доставки еды. Заказчик просит найти инсайты для повышения удержания пользователей и улучшения взаимодействия с партнёрами-ресторанами. Вопросы: как ведут себя пользователи, какой путь проходят, где «проваливаются», как улучшить работу с ресторанами.

## Данные
Данные сервиса доставки еды за май-июль 2021 года: события пользователей, заказы, рестораны, выручка (205 503 записи).

## Задача
Найти инсайты для повышения удержания пользователей и улучшения взаимодействия с партнерами. Проанализировать пользовательский путь через воронку конверсий, провести RFM-сегментацию аудитории и кластеризовать рестораны методом K-Means.

## Используемые библиотеки
*pandas, numpy, matplotlib, seaborn, scipy, sklearn*

## Ключевые выводы
- Найдена главная точка потерь: подтверждение телефона на мобильных устройствах (конверсия падает до 55% против 90% на десктопе).
- RFM-анализ показал высокую долю одноразовых клиентов.
- Выделено 4 кластера ресторанов, для каждого предложена своя маркетинговая стратегия.
