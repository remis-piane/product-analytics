# Портфолио проектов по продуктовой аналитике

Привет! Меня зовут Михаил. Здесь собраны проекты по продуктовой аналитике, выполненные в рамках курса «Продуктовый аналитик» от Яндекс.Практикум.

Все проекты — самостоятельные исследования на основе реальных бизнес-кейсов: от расчёта продуктовых метрик и unit-экономики до дизайна и анализа A/B-тестов, сегментации пользователей и кластеризации партнёров.

### Список проектов

| Название проекта | Описание | Используемые библиотеки |
| :--- | :--- | :--- |
| [01. Анализ системы метрик приложения](./01-product-metrics-analysis) | Оценка unit-экономики развлекательного приложения: расчет DAU/MAU/Stickiness, CAC/LTV/ROI за 28 дней, когортный анализ каналов привлечения. | *pandas, numpy, matplotlib, seaborn* |
| [02. Разработка A/B-тестирования](./02-ab-test-design-analysis) | Расчет параметров A/B-теста для нового алгоритма рекомендаций, проверка корректности сплита и оценка статистической значимости. | *pandas, numpy, statsmodels, scipy* |
| [03. Поиск инсайтов и точек роста](./03-user-journey-rfm-clustering) | Анализ воронки пользовательского пути сервиса доставки, RFM-сегментация клиентов и K-Means кластеризация ресторанов-партнеров. | *pandas, numpy, matplotlib, seaborn, sklearn* |
| [04. Исследование результатов А/В-теста](./04-ab-test-onboarding-analysis) | Анализ влияния обновленного онбординга на депозиты в финтех-приложении, использование бутстрапа и анализ перцентилей. | *pandas, numpy, scipy, statsmodels* |
| [05. Обзор бизнес-показателей маркетплейса](./05-marketplace-metrics-analysis) | Комплексный аудит метрик и юнит-экономики маркетплейса. Поиск инсайтов по каналам и категориям. Дизайн и анализ A/B-теста бонуса на первую покупку для TikTok. | *pandas, numpy, matplotlib, seaborn, scipy, statsmodels, plotly* |
